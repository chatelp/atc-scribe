The sign is the radar scope; use these files as they are, never redrawn. `signe` (64 grid, dark grounds; the source of every size from 24 px up) and `signe-16` (below 24 px, no range ring) are the running state; `signe-actif` and `signe-actif-16` are the listening state (the lit scope), shown while a frequency plays in this browser; `signe-clair` is for light grounds (ink `#1a1a1a`, green `#2e7d32`). `marque` and `marque-clair` set the sign with the name in the machine's monospace (the name is not outlined). `favicon` and `favicon-actif` are the tab icons (a `#1a1a1a` tile). The three `barre-menus-*` files are 18 pt macOS template images in black ink and alpha, tinted by the system: running, stopped, and listening (that one keeps its colours on purpose).
