Our own family of nine aircraft silhouettes, drawn by `tools/design/avions.mjs` from real dimensions on a 64 grid, single black ink (`#000000`): the map renderer tints them with the altitude ramp (`color-altitude-dark-*` on dark maps). `leger` (light piston, DR400 · C172), `turboprop` (ATR 72), `affaires` (business jet, Falcon 2000), `bireacteur` (narrow-body twin, A320), `gros` (wide-body twin, A350), `quadri` (four-engine, B747), `helico` (H125), `planeur` (glider, ASK 21), `inconnu` (a chevron, type unknown). Map sizes in px: inconnu 18, leger 20, affaires · helico · planeur 22, turboprop 24, bireacteur 26, gros 30, quadri 32. Use the class silhouette for a type, never a picture of a real aircraft.
