# Badge

A badge marks a row with a short code; an age says how old a value is.

**Markup.** `<span class="cl-badge">LP</span>`: LP (last known position, GPS lost), S (Mode S, no position), a followed airport's code when several are followed. `<span class="cl-age">−12 s</span>`: the age of the last message, shown from 5 s; also counts and remarks in mono caption.

**Rules.** Every badge has a `title` that says it in words. Ages do not blink.
