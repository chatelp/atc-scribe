# EmptyState

An empty state says what will appear and how to make it appear.

**Markup.** `<div class="cl-empty">`: a 16 px icon in `color-text-tertiary`, then a sentence in `text-small` `color-text-secondary`.

- Do: "No transcription yet on 124.350. Lines appear here as soon as someone speaks."
- Don't: "No data".
