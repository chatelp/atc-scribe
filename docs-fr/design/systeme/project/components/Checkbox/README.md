# Checkbox

A checkbox or a switch sets one option in the settings page.

**Markup.** `<label class="cl-check"><span class="cl-check__box"></span> Label</label>`; `is-on` when checked; `cl-check--radio` for one choice among several (a ring and a dot). Switch: `<span class="cl-switch" role="switch" aria-checked>`; `is-on` when on.

**Rules.** The label sits right of the box and is clickable, `text-body` in settings. Outline `color-border-control` (3:1); checked fill `color-accent-default` with an `color-text-on-accent` tick. Switch 28 × 16 on the desk.
